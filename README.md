# Resume Landing Page

Personal resume landing page. Dark theme, elegant, luxurious, unique.

## Concept

Scroll-driven hero: MacBook opens → displays content → closes halfway as scroll progresses. Pure black void background with teal/cyan accent glow, Apple-keynote aesthetic.

## Structure

```
/assets
  /images          Hero MacBook frames (closed / open / half-closed)
  /videos          Veo-generated scroll clips
/moodboard         Inspiration references
/docs              Design decisions, prompts, copy
```
