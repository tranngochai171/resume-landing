## Lessons Learned (for iteration)

- **Nano Banana Pro ignores degree numbers** — use visual metaphors ("L-shape", "wedge", "like a book closing", "stands upright like a monitor")
- **Veo misreads camera orbits as subject rotation** — keep camera locked, animate only the subject
- **Side-profile angle changes break continuity** — lock front 3/4 across all frames
- **Hard cuts > camera moves** for multi-angle sequences in Veo
- **Veo 3 generates audio by default** — always add "Silent, no audio"
- **Veo watermark cannot be removed for free** — crop 10-15% off the watermarked corner or overlay UI element
